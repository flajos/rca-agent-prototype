# Synthetic RCA Case 01 – Engine Room Fire (Near Miss)

This dataset is a **complete synthetic RCA test suite** intended to validate a
Smart RCA workflow and agent-based RCA creation.

The package includes:
- Realistic source documents (logs, statements, SMS excerpts)
- Manual input forms (what a human might type)
- A **Gold Standard RCA** representing an acceptable, class-society-ready outcome

Incident summary:
- Minor engine room fire caused by fuel oil leak on auxiliary engine no.2
- Fire extinguished quickly using fixed CO₂ system (partial release)
- No injuries; machinery damage limited
- Incident classified as a Near Miss with High Potential

Intended use:
- Run Smart RCA workflow end-to-end
- Compare agent-generated RCA vs Gold Standard RCA
- Validate evidence traceability, completeness, and methodology quality
